## Approach

The recurring workflow is:

~~~text
observe
  -> form a hypothesis
  -> run the smallest useful experiment
  -> interpret the evidence
  -> reduce the search space
  -> solve
~~~

This is the habit I am trying to carry from CTFs into real security work.
